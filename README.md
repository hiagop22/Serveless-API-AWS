# 🚀 Serverless API with AWS Lambda, FastAPI, and Terraform

This repository contains a **serverless API** built with **FastAPI**, deployed on **AWS Lambda**, and fully managed via **Terraform** following Infrastructure as Code (IaC) principles.  

The project implements **JWT authentication**, **Swagger documentation**, a **Pytest test suite**, and **Docker multi-stage builds**. Deployment and testing are automated through **GitHub Actions** with protected branches, ensuring secure and reliable CI/CD pipelines.  

🌐 Public endpoint available at `/` (no authentication required).  
🔒 All other endpoints are secured with **JWT Bearer authentication**.  


---

## ⚠️ Educational Note — Anti-Pattern: Mixing Infra & App Deployment

> “Mixing application deployment with infrastructure deployment (e.g. having Terraform deploying apps with the Helm provider)” — from [Kubernetes Anti-Patterns](https://codefresh.io/blog/kubernetes-antipatterns-1/)

This repository **intentionally demonstrates this anti-pattern for didactic purposes only**.  
**Best practice:** separate concerns — use Terraform for infrastructure provisioning and handle application deployment via CI/CD pipelines and prebuilt artifacts (e.g., Docker images), with independent lifecycles and approvals.

## 🚀 CI/CD with GitHub Actions

All deployments are automated using **GitHub Actions**.  

- ✅ **Pull Requests** → run tests + Terraform plan for review  
- ✅ **Push to `main`** → build, test, provision, and deploy API to AWS Lambda  
- ✅ **Manual Approval Stage** → review pipeline before production updates  
- ✅ **Commit Blocking on Failure** → if tests or build fail, the commit cannot be merged or deployed

Workflows are stored under [`.github/workflows/`](.github/workflows/).

## ⚙️ Local Development
1. Configure AWS Credentials

Export credentials to your shell (or configure via aws configure):
```bash
export AWS_ACCESS_KEY_ID="your-access-key"
export AWS_SECRET_ACCESS_KEY="your-secret-key"
export AWS_REGION="us-east-1"
```

2. Initialize Terraform
```bash
terraform init
terraform workspace new dev   # optional, create dev environment
terraform workspace select dev
terraform plan -out=tfplan.out
terraform apply tfplan.out
```

3. Destroy Infrastructure (⚠️ Danger Zone)

To remove all deployed resources:

```bash
terraform destroy
```
